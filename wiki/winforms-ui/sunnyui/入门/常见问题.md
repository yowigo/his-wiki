## 显示 / DPI / 字体

### 1. 升级到 V3.5.0+ 后字体不一致

按 [多页面框架/全局字体设置.md](../多页面框架/全局字体设置.md) 设置全局字体。

### 2. 运行时界面比设计期大（高分屏放大）

三步组合方案：

1. **窗体和自定义 UserControl** 都设 `AutoScaleMode = None`
2. **app.manifest** 启用 `dpiAware=true`
3. **UIStyleManager** 设 `DPIScale = true`（**编译时 DPI 必须 100%**）

```xml
<application xmlns="urn:schemas-microsoft-com:asm.v3">
  <windowsSettings>
    <dpiAware xmlns="http://schemas.microsoft.com/SMI/2005/WindowsSettings">true</dpiAware>
    <longPathAware xmlns="http://schemas.microsoft.com/SMI/2016/WindowsSettings">true</longPathAware>
  </windowsSettings>
</application>
```

完整方案见 [多页面框架/DPI缩放自适应方案.md](../多页面框架/DPI缩放自适应方案.md)。

### 3. 高清屏下字体模糊

同 Q2，加上 app.manifest 的 dpiAware 即可。

## 主题 / 颜色

### 4. 编辑期设了颜色，运行起来颜色变了

SunnyUI 有主题统一管理（UIStyleManager），运行期主题会覆盖手动设的颜色。

**解决**：要保留自定义颜色，控件设 `Style = Custom` **且** `StyleCustomMode = true`。详见 [入门/主题.md](主题.md)。

## 窗体 / 框架

### 5. UIForm 设 `IsMdiContainer = true` 无效

SunnyUI **不支持 MDI**，有自己的多页面框架（IFrame + UIPage + PageIndex）。见 [多页面框架/简述及示例.md](../多页面框架/简述及示例.md)。

### 6. 继承的窗体上有小锁，控件属性改不了

类似类继承的 private 父类属性——父窗体为保证继承窗体 UI 设计完整性，锁定了关键控件。父窗体已经把事件封装到父类，**通过事件接入**而不是直接改控件。

举例：继承 UILoginForm 的登录按钮，去**事件面板**找已封装好的事件。

### 7. 框架页面切换时每次要刷新

SunnyUI 的 UIPage 生命周期有 4 个钩子（**选一个用就行**）：

| 钩子 | 时机 |
| --- | --- |
| `FormLoad`（需设 `NeedReload = true`） | 每次切换进入页面 |
| `protected override OnLoad()` | 每次切换进入页面 |
| `public override Init()` | 每次切换进入页面 |
| `public override Final()` | 每次切换离开页面 |

## 编译 / 引用

### 8. 从码云下载源码编译报错

**源码编译需要 VS2022**，安装 .NetFramework4.0 目标包：[安装步骤](https://www.cnblogs.com/yhuse/p/15536393.html)

错误"未识别 TargetFramework `net5.0-windows`" → VS 版本低，.NET5 需 VS2019 16.8+；.NET6 需 VS2022 17.0+。

### 9. 依赖项显示黄色感叹号

Nuget 服务器连不上 → 切到国内源：

```
程序包源：https://nuget.cdn.azure.cn/v3/index.json
```

### 10. `SunnyUI.dll 中没有可放置在工具箱上的组件`

项目环境不能是 `.Net Framework 4 Client Profile` → 改成完整版 4.0+。

### 11. 拖控件到窗体时报错

工具箱里的控件版本和项目引用版本不一致 → **删除工具箱中的 SunnyUI 控件、重建添加**，再拖。

### 12. 未能加载程序集

确认引用了 **SunnyUI.dll** + **SunnyUI.Common.dll**（**两个都必须**）。VS 偶尔抽风时：**删除两个引用 → 重新引用**。

## 设计器 / .NET 6+

### 13. .NET 5/6/7 下 UINavBar 报错、Symbol 没有点击按钮

WinForms 设计器问题，参考 [dotnet/winforms#6193](https://github.com/dotnet/winforms/issues/6193)。**建议项目运行环境换回 .NetFramework**。

### 14. "文件中的类都不能进行设计，因此未能为该文件显示设计器"

按顺序排查：

1. 确认编译环境符合项目要求
2. Nuget 引用没黄色感叹号
3. 清理项目 → 重新编译 → 关掉 VS → 重新打开

### 15. `.resx 因为它位于 Internet 或受限区域中... 请删除 Web 标记`

资源文件被 Windows 标记为 Web 来源。打开文件属性 → **解除锁定**。

### 16. UILogo 工具箱里找不到

UILogo 未加入工具箱（为定制版预留）。直接放一张图片即可替代。

### 17. 数字代号是什么？

WEB 开发常见的**字体图标编号**。见 [入门/字体图标.md](字体图标.md)。
