# 主题系统

> raw 原文：`raw/SunnyUI文档/主题.md` ｜ raw 同步：V3.9.7 / 2026-05-21

SunnyUI 主题由 **Color / Rect / Radius / Font / Style** 五个维度组成，参考 Element 设计风格。

---

## 1. Color 色彩（主色 + 辅助色 + 中性色）

| 类别 | 用途 |
| --- | --- |
| 主色 | 鲜艳蓝色为品牌主色，按钮 / 链接 / 高亮 |
| 辅助色 | 红色表示危险操作、橙色警告、绿色成功等场景色 |
| 中性色 | 文本、背景、边框，通过深浅区分层次 |

## 2. Rect 边框

| 属性 | 含义 |
| --- | --- |
| `RectColor` | 边框颜色 |
| `RectDisableColor` | 控件不可用时边框颜色 |
| `RectSides` | 边框显示方向：None / All / Top / Bottom / Left / Right |

**陷阱**：边框显示受**圆角设置**影响——如果某侧两端为圆角，该侧边框必定显示（不能用 RectSides 隐藏）。

## 3. Radius 圆角

| 属性 | 含义 | 默认 |
| --- | --- | --- |
| `Radius` | 圆角大小（px） | 5 |
| `RadiusSides` | 四个角分别是否圆角：可独立设置 |

**大圆角效果**：把 `Radius` 设为与控件高度相等（例：Size 100×35 + Radius 35）→ 胶囊按钮。

## 4. Font 字体

- 默认：Windows 默认字体（中文 → 宋体，大小 12）
- 全局字体修改见 [多页面框架/全局字体设置.md](../多页面框架/全局字体设置.md)
- **版权提醒**：界面引用字体注意版权。免费字体：思源黑体、阿里巴巴普惠体、小米 MiSans、鸿蒙 HarmonyOS
- **微软雅黑警告**：仅限屏幕显示，宣传页/视频/广告需自行取得微软授权

## 5. Style 主题样式（核心）

```csharp
// 全局设置
UIStyleManager.Style = UIStyle.Blue;
```

### 内置主题枚举

| Element 风格（11 个） | 其他 |
| --- | --- |
| Blue（默认）、Green、Orange、Red、Gray、Purple、LayuiGreen、LayuiRed、LayuiOrange、DarkBlue、Black | Custom、Inherited、Dark（V3.9.5+ 新增） |

### `StyleCustomMode` —— **最大踩坑点**

| StyleCustomMode | 行为 |
| --- | --- |
| `false`（默认） | 使用 UIStyleManager 统一主题，任何手动改的颜色**运行期被覆盖** |
| `true` | 接受用户自定义颜色，**不受** UIStyleManager 主题约束 |

**关键规则**：要让自定义颜色生效，必须**同时**设：

```csharp
button.Style = UIStyle.Custom;
button.StyleCustomMode = true;
button.FillColor = Color.OrangeRed;  // 此时才生效
```

V3.6.0+ 起，主题做了重构，自定义颜色"所见即所得"——不切换全局主题时，颜色修改可直接保存。但**一旦切换全局主题**，仍需走 `Custom + StyleCustomMode=true` 才不被覆盖。详见 [升级指南/3.5.2-3.6.0.md](../升级指南/3.5.2-3.6.0.md)。

## UIStyleManager 组件

放到主窗体上即可统一管理主题。关键属性：

| 属性 | 含义 |
| --- | --- |
| `Style` | 全局主题 |
| `StyleCustomMode` | 同上 |
| `DPIScale` | DPI 缩放字体自适应（必须编译时 DPI=100%） |
| `GlobalFont` | 启用全局字体 |
| `GlobalFontName` | 全局字体名 |
| `GlobalFontScale` | 全局字体缩放比例（100 = 12px） |
| `MultiLanguageSupport` | 启用多语言（V3.7.2+） |
