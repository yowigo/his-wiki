# 国际化（多语言）

> raw 原文：`raw/SunnyUI文档/国际化.md` ｜ raw 同步：V3.9.7 / 2026-05-21

V3.7.2 重构了多语言支持。旧版 `UILocalize` 类 → 新版 `UIStyles.CurrentResources`。本页面以 V3.7.2+ 为主。

---

## V3.7.2+ 三类资源

1. **控件内置字符串**：SunnyUI 控件自身的"提示/确定/取消"等 → `UIStyles.CurrentResources.*`
2. **窗体上的控件字符串**：窗体（UIForm/UIForm2/UIPage）上的控件 Text（**不含用户控件**） → 由 `TranslateHelper.LoadCsproj()` 扫描生成
3. **代码内字符串**：散落在 `.cs` 代码中的提示文字 → 通过 `CodeTranslator` 子类管理

配置文件用 **Ini 编码 UTF8** 保存，路径：`<可执行文件夹>/Language/`。

---

## 快速集成（按步骤）

### 1. 启用多语言

```csharp
UIStyles.MultiLanguageSupport = true;
// 或在 UIStyleManager 上把 MultiLanguageSupport 设为 true
```

### 2. Program.cs 注册额外语言 + 生成翻译资源

```csharp
// 内置默认只有简体中文(zh_CN)和英文(en_US)，新增繁体中文：
UIStyles.BuiltInResources.TryAdd(CultureInfos.zh_TW.LCID, new zh_TW_Resources());

// 扫描 csproj 生成多语翻译配置（首次运行后可注释掉）
TranslateHelper.LoadCsproj(@"D:\Source\SunnyUI\SunnyUI.Demo\SunnyUI.Demo.csproj");
```

### 3. 切换语言

```csharp
UIStyles.CultureInfo = CultureInfos.zh_CN;  // 简体中文
UIStyles.CultureInfo = CultureInfos.zh_TW;  // 繁体中文
UIStyles.CultureInfo = CultureInfos.en_US;  // 英文
```

### 4. 重载窗体翻译

```csharp
public override void Translate()
{
    base.Translate();  // 必须保留
    CodeTranslator.Load(this);
    this.CloseAskString = CodeTranslator.Current.CloseAskString;
    // ...逐条赋值
    this.uiNavBar1.Invalidate();
}

private class CodeTranslator : IniCodeTranslator<CodeTranslator>
{
    public string CloseAskString { get; set; } = "您确认要退出程序吗？";
    public string Forms { get; set; } = "窗体";
    // ...其他默认值
}
```

### 5. 生成翻译 Ini 文件

运行程序后，依次切换三种语言并打开各 UIPage，自动生成对应 Ini 文件到 `Language/` 目录。然后注释掉 Program.cs 里的 `LoadCsproj()` 调用。

## 语言 ID（LCID）速查

| LCID | 语言 |
| --- | --- |
| 2052 | zh-CN 简体中文 |
| 1028 | zh-TW 繁体中文 |
| 1033 | en-US 英文 |

完整列表：[MS-LCID](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-lcid/a9eac961-e77d-41a6-90a5-ce1a8b0cdb9c)

## Ini 文件结构

```ini
[Info]                          # 语言列表（自动生成，勿手改）
2052.Name=zh-CN
1033.Name=en-US

[2052.FormResources]            # 窗体控件资源（修改 = 号右边）
NHome.Text=主页

[2052.CodeResources]            # 代码字符串资源（修改 = 号右边）
CloseAskString=您确认要退出程序吗？

[Controls]                      # 可翻译控件列表（自动生成，勿手改）
Count=9
Control0=...
```

**编辑规则**：

- ✅ 只改 `=` 号右边的值
- ❌ `[Info]` `[Controls]` 不要手动改
- ❌ 修改前必须先**关闭应用程序**，否则可能被代码覆盖
