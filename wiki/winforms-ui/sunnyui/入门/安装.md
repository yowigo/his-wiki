# 安装

> raw 原文：`raw/SunnyUI文档/安装.md` ｜ raw 同步：V3.9.7 / 2026-05-21

---

## 方式一（推荐）：Nuget 安装

```
PM> Install-Package SunnyUI
```

或在 VS Nuget 包管理器搜索 `SunnyUI` 安装。Nuget 引用安装后，工具箱会**自动添加** SunnyUI 控件，无需手动注册。

## 方式二：手动 DLL 引用

1. 从 [gitee.com/yhuse/SunnyUI](https://gitee.com/yhuse/SunnyUI) 下载 ZIP 解压
2. 引用编译好的 `SunnyUI.dll` + `SunnyUI.Common.dll`（**两个都必须**）
3. VS 工具箱 → 右键 → 添加选项卡 `SunnyUI`
4. 在该选项卡内右键 → 选择项 → 浏览 `SunnyUI.dll`，或直接拖 DLL 进去

## 环境约束

| 项 | 要求 |
| --- | --- |
| 源码编译 | VS2022（17.8+ 才支持 .NET8） |
| 动态库使用 | VS2010 及以上 |
| 框架 | .Net Framework 4.0+ / .Net 6 / .Net 7 / .Net 8 |
| ❌ 不支持 | **.Net Framework 4 Client Profile** |

## 常见安装失败

| 现象 | 排查 |
| --- | --- |
| `SunnyUI.dll 中没有可放置在工具箱上的组件` | 项目环境是 .Net Framework 4 Client Profile → 改成完整版 .Net Framework 4.0+ |
| 依赖项目显示感叹号 | Nuget 包源连不上，切到国内源 `https://nuget.cdn.azure.cn/v3/index.json` |
| 拖控件到窗体报错 | 工具箱版本和项目引用版本不一致 → 删除工具箱里的控件、重建添加再拖 |
| 未识别 TargetFramework `net5.0-windows` / `net6.0-windows` | VS 版本太低，.NET5 需 VS2019 16.8+，.NET6 需 VS2022 17.0+ |
