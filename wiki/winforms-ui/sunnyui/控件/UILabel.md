# UILabel — 标签

> raw 原文：`raw/SunnyUI文档/控件/UILabel.md` ｜ raw 同步：V3.9.7 / 2026-05-21

## 速查

- **默认属性**：`Text` ｜ **默认事件**：`Click`
- 最简单的标签控件，仅文本 + 主题色

## 特有属性

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `Text` | string | - | 显示文本 |
| `ForeColor` | Color | - | 字体颜色 |

> 几乎没有专有属性，主要靠通用主题接管颜色。需要超链接见 [UILinkLabel](UILinkLabel.md)，需要标签条纹见 [UIMarkLabel](UIMarkLabel.md)，需要字体图标见 [UISymbolLabel](UISymbolLabel.md)，需要 LED 风格见 [UILedLabel](UILedLabel.md)。
