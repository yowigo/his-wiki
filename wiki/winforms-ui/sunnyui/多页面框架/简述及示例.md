# 多页面框架 — 简述及示例

> raw 原文：`raw/SunnyUI文档/多页面框架/简述及示例.md` ｜ raw 同步：V3.9.7 / 2026-05-21

## 框架结构

```
框架（IFrame） = UIForm + UITabControl
页面（UIPage） × N  （每页有唯一 PageIndex）
```

SunnyUI 不支持原生 MDI，用这套自有框架替代。

## 核心 API（IFrame 接口的三个方法）

| 方法 | 作用 |
| --- | --- |
| `AddPage(UIPage page)` | 添加页面到框架 |
| `ExistPage(int pageIndex)` | 检查 PageIndex 是否已存在 |
| `SelectPage(int pageIndex)` | 切换到指定 PageIndex |

## 完整 Demo

### 1. 新建框架窗体（FCustomMain）

1. 新建 Form → 改为 `UIForm` + `using Sunny.UI;`
2. **窗体 AutoScaleMode = None**（关键，必做）
3. 拖一个 `UITabControl` 到窗体上
4. 设窗体的 `MainTabControl` 属性 = 这个 UITabControl

### 2. 新建页面（FPage1 / FPage2 / FPage3）

1. 新建 Form → 改为 `UIPage` + `using Sunny.UI;`
2. AutoScaleMode = None
3. **设 `PageIndex`**：正整数、唯一，例如 1001 / 1002 / 1003

### 3. 框架按钮联动页面

```csharp
private void uiButton1_Click(object sender, EventArgs e)
{
    if (!ExistPage(1001))
        AddPage(new FPage1());
    SelectPage(1001);
}

private void uiButton2_Click(object sender, EventArgs e)
{
    if (!ExistPage(1002))
        AddPage(new FPage2());
    SelectPage(1002);
}
```

## 内置模板 vs 自定义模板

| 类型 | 灵活度 | 适用 |
| --- | --- | --- |
| **内置模板**（7 种风格） | 低 | 想快速开干、能接受模板样式 |
| **自定义模板**（手动 IFrame） | 高 | 需要特殊布局或交互 |

参考：SunnyUI.Demo.exe → 窗体 → Frames → 自定义模板 / 内置模板。

## UIPage 生命周期钩子

每次切换进入/退出页面会触发：

| 钩子 | 时机 | 用法 |
| --- | --- | --- |
| `FormLoad` + `NeedReload = true` | 切换进入 | 处理需重新刷新的数据 |
| `override OnLoad()` | 切换进入 | 类似 Form 的 OnLoad |
| `override Init()` | 切换进入 | SunnyUI 推荐的初始化点 |
| `override Final()` | 切换离开 | 清理/保存状态 |

**三个进入钩子选一个用即可**，不要重复挂逻辑。
