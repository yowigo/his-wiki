# 全局字体设置

> raw 原文：`raw/SunnyUI文档/多页面框架/全局字体设置.md` ｜ raw 同步：V3.9.7 / 2026-05-21

V3.5.0 起 SunnyUI 默认字体为系统默认字体，可全局指定字体名称与缩放比例。

---

## 配置流程

### 1. 先完成 DPI 适配

按 [DPI缩放自适应方案.md](DPI缩放自适应方案.md) 三步走。**全局字体依赖 DPI 适配**。

### 2. UIStyleManager 配置

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `DPIScale` | bool | 必须 true（先决条件） |
| `GlobalFont` | bool | true 启用全局字体 |
| `GlobalFontName` | string | 全局字体名（可下拉选择） |
| `GlobalFontScale` | int | 全局字体缩放比例（**默认 100 = 12px**） |

### 3. 缩放比例对照

| GlobalFontScale | 实际字号 |
| --- | --- |
| 75 | 9px |
| 100（默认） | 12px |
| 125 | 15px |

公式：`字号 = 12 × Scale / 100`

### 4. 运行时切换全局字体

```csharp
UIStyles.DPIScale = true;
UIStyles.GlobalFont = true;
UIStyles.GlobalFontName = cbFont.Text;        // 用户选择的字体名
UIStyles.GlobalFontScale = uiTrackBar1.Value; // 滑块值，例如 75-125
UIStyles.SetDPIScale();                       // 应用
```

参考 SunnyUI.Demo.exe → 多彩主题示例。
