# 升级指南：3.5.2 → 3.6.0

> raw 原文：`raw/SunnyUI文档/升级指南/3.5.2--_3.6.0.md` ｜ raw 同步：V3.9.7 / 2026-05-21

主题机制重构、个别控件事件签名变更。

---

## 1. 主题机制重构

V3.6.0 **隐藏了 `StyleCustomMode` 属性**——但底层规则未变。

### 不切换全局主题

- 所有控件颜色修改"**所见即所得**"
- 窗体关闭后再打开，颜色会被保存
- 默认主题：`UIStyle.Inherited`（继承全局主题）

### 切换全局主题

- 默认行为：切换主题时，控件自定义颜色被覆盖
- 想保留自定义颜色：改完颜色后把 `Style` 设为 `UIStyle.Custom`

**关键**：底层逻辑没变，仍然是 `Style = Custom + StyleCustomMode = true` 才不被主题覆盖；只是 IDE 上 StyleCustomMode 不再可见——SunnyUI 替你自动处理。

## 2. UICheckBoxGroup ValueChanged 签名变更

**旧（V3.5.2-）**：

```csharp
private void uiCheckBoxGroup1_ValueChanged(
    object sender, int index, string text, bool isChecked)
```

**新（V3.6.0+）**：

```csharp
private void uiCheckBoxGroup1_ValueChanged(
    object sender, CheckBoxGroupEventArgs e)
```

需要按 Demo 示例修改事件处理。

## 3. UIForm 默认值变更

| 属性 | V3.5.2 默认 | V3.6.0 默认 |
| --- | --- | --- |
| `ShowShadow` | false | **true** |
| `ShowRadius` | true | **false** |

ShowShadow 打开时，**Win11 会显示圆角窗体**。不需要可设 ShowShadow = false。
