# 医保结算对账使用手册

## 1. 业务背景：为什么要对账

医院每完成一笔医保结算，会把结算流水（费用总额、基金支付、个人账户支付等）报到医保中心。**对账**就是医院把「本地汇总的结算数据」与「医保中心记录的结算数据」逐日核对，确认两边金额、笔数一致（账平）。

对账的意义：

- 医保中心按**对账结果**与医院结付（拨钱）——账不平的日期/险种，资金结付会受影响
- 发现医院本地与中心记录不一致，尽早排查（漏报、重复报、金额差异、退费未冲正等）

本项目对账分两条线：

| 线路 | 通道 | 入口 | 交易 |
|---|---|---|---|
| 国家医保 | CSB HTTP | 菜单 1020 → `Frm结算对帐` | 3201 对总账 / 3202 对明细账 / 9101 文件上传 / 9102 文件下载 |
| 上海五期 | SendRcv4 | 菜单 1021 → `Frm医保五期登记查询对账` | SL01 对账（手工调试式） |

两线共用同一套结算流水数据（按系统区分），但**对账记录只有国家对账会生成**，五期不产生对账记录。

## 2. 基本概念

| 概念 | 说明 |
|---|---|
| 险种类型 | 310 职工基本医疗保险 / 390 城乡居民基本医疗保险 |
| 清算类别 | 11 门诊 / 21 住院 |
| 清算经办机构 | 本地结算流水中的经办机构编码（如 03、321099 表示本地直结，其余为异地/代办） |
| 账平 / 账不平 | 3201 对总账返回 `stmt_rslt`：`0`=账平，非 `0`=账不平（带原因说明） |
| 主记录 / 明细记录 | 对账按「日期」产生一条主记录，按「险种 × 清算类别 × 经办机构」逐行产生明细记录 |
| 对账状态 | `0` 未对账（对账但全不平）/ `1` 已对账（全部账平）/ `2` 部分对账（部分账平） |
| 申报状态 | 未申报 / 已申报（申报是后续环节，当前界面未开放操作） |

## 3. 国家对账：对账功能（`Frm结算对帐` → 对账功能页）

> 菜单 1020 打开后，默认落在「对账功能」页。

### 3.1 查总账

1. 顶部选择**对账日期**（单日，默认今天；历史对账选历史日期）
2. 点【查询】→ 从本地结算流水汇总出「总账」，按 险种 × 清算类别 × 清算经办机构 分行：
   - 每行 = 一类结算的本地汇总（医疗费总额 / 基金支付总额 / 个人账户支付金额 / 现金支付总额 / 结算笔数 / 结算经办机构）
   - 汇总口径：正金额结算 + 退费流水（负金额按「原结帐ID」关联原流水，归入原流水所在险种/类别），即退费不单独成行、冲抵原结算

### 3.2 对总账（核心操作）

1. 点【对账】→ 对总账的每一行调 **3201 对总账**（把本地的险种、清算类别、日期、经办机构、金额、笔数发给中心核对）
2. 返回后该行「对账结果」列显示：`账平` 或 `账不平,<原因>`
3. 结果自动保存：
   - 同一天重复对账 = **更新覆盖**，不产生多条
   - 全部处理完弹出汇总：`成功 N 条 / 总计 M 条`
4. 主记录最终状态：全部账平 → `1 已对账`；部分账平 → `2 部分对账`；全部不平 → `0 未对账`

⚠️ 注意：**只要执行过【对账】，对账记录就产生了**（即使全部账不平，状态 `0` 也会保存）。一次对账中只要有一行调 3201 失败，本日期对账流程立即中止（不继续后续行）。

### 3.3 明细对账（核对到每一笔结算）

总账只核对汇总数，对不平的行要进一步核对到明细笔：

1. 选中总账中要核对的行（选中后点【对明细】）
2. 系统自动执行：
   - 查本地该行对应险种/类别/经办机构下的全部结算明细 → 生成 txt 文件 → 压缩
   - 调 **9101 文件上传** 上传压缩包
   - 调 **3202 对明细账**（附总金额、笔数、清算类别）
   - 自动调 **9102 文件下载**，把中心明细文件下载并解压到本地
3. 「本地明细」「中心明细」两个表格分别展示两边数据，逐笔核对（结算ID、就诊ID、人员编号、金额、退费结算标志）
4. 下载的中心明细文件存放在：程序目录 `目录下载\<文件查询号目录>\result.txt`

### 3.4 浏览按钮

- 【本地浏览】/【中心浏览】：手动选择 txt 文件加载对比，方便核对历史文件
- 本地文件列：结算ID、就诊ID、人员编号、医疗费总额、基金支付总额、个人账户支出、退费结算标志
- 中心文件列：人员编号、就诊ID、结算ID、发送方报文ID、对账结果、退费结算标志、备注、医疗费总额、基金支付总额、个人账户支出、字段扩展

## 4. 国家对账：对账记录查询（`Frm结算对帐` → 对账记录查询页）

点「对账记录查询」按钮进入，用于查历史对账结果。

1. 查询条件：
   - 日期范围（默认本月 1 号 ~ 今天）
   - 对账状态（**默认「未对账」**，可切 全部 / 未对账 / 已对账 / 部分对账）
   - 险种类型、清算类别、对账结果（账平/账不平）
2. 主列表：对账日期、状态（行色：已对账=浅绿、部分对账=浅黄）、对账时间、操作员、申报状态
3. **双击某行** → 切到明细页，看该日每行险种/类别的本地金额 vs 中心金额、对账结果（账不平行标红）
4. 「查询明细」按钮 → 直接按条件查明细记录

⚠️ 前提：**必须先执行过对账，列表才有数据**（对账记录是对账动作产生的，不是按日期预生成的）。

## 5. 上海五期对账（`Frm医保五期登记查询对账`）

> 菜单 1021 打开。这是一个**接口调试工具**（选交易 → 填参 → 调用 → 看返回），不是批量业务界面。

对账操作：

1. 交易类型选择「SL01 对账」
2. 填写参数（全部手填，来自当天本地结算汇总）：
   - 对账日：yyyyMMdd
   - 中心流水号数量：当天结算笔数
   - 当年账户支付总额 / 历年账户支付总额 / 现金自负总额 / 统筹支付总额 / 附加支付总额 / 分类自负总额 / 非医保范围费用总额：当天各类金额汇总
3. 点【调用交易】→ 返回结果展示在下方（成功/失败及原因）
4. 入参可【清空】后重填

⚠️ 边界：五期 SL01 对账**不产生对账记录**，也不会出现在「对账记录查询」列表中；SL01 之后如需查明细，用五期其它查询交易（SJ31 等）辅助核对。

## 6. 数据保存与文件位置

| 内容 | 说明 |
|---|---|
| 对账记录 | 国家对账产生的对账记录自动保存；同一天重复对账 = 更新覆盖，不新增 |
| 本地明细文件 | 【对明细】生成的本地结算明细 txt，存放在程序目录 `明细对账文件\<时间戳>\` 下 |
| 中心明细文件 | 9102 下载解压的中心明细文件，存放在程序目录 `目录下载\<文件查询号目录>\` 下（文件名为 result.txt） |

## 7. 常见问题 FAQ

| 问题 | 原因 / 处理 |
|---|---|
| 对账记录查询列表没有数据 | 该日期从未执行过【对账】。先到「对账功能」选日期对账，记录才会生成 |
| 查「未对账」没有数据 | 正常——`0 未对账` 只在「对账了但全部不平」时出现；对过且全平的日期是 `1 已对账` |
| 同一天对账多次，列表怎么只有一条 | 重复对账 = 更新覆盖，不新增 |
| 中心金额列全是 0.00 | 已知遗留：对账记录查询中「中心金额」暂不写入数值，不影响对账结果核对；逐笔核对请以「对明细」的本地/中心明细表格为准 |
| 对账中途报错中止 | 3201 失败即中止。重试【对账】即可，已对成功的行不受影响 |
| 明细对账的文件在哪 | 本地明细：程序目录 `明细对账文件\`；中心明细：程序目录 `目录下载\` 下的解压目录（result.txt） |
| 五期对账记录查不到 | 五期 SL01 不产生对账记录，且五期/国家对账记录互不可见 |
| 异地/代办结算 | 总账按「清算经办机构」分行，`03`/`321099` 与异地经办机构分开核对，对账时互不影响 |

## 8. 上线前注意事项

- 对账是**面向医保中心的对外交易**，金额/笔数直接决定结付——操作前确认日期正确、总账数据齐全（当天结算完成后再对账）
- 生产环境首次使用，建议先用小日期（如昨天）试对一次，确认账平再铺开
- 账不平不要反复点对账掩盖问题，先查明细文件定位差异（漏报 / 重复 / 退费未冲正）
