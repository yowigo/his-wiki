# 未医保结算住院交易上传（报文编号 0103）

## 功能描述

记录**未医保结算**住院费用信息的基本信息、出院信息、住院费用信息及费用明细信息等，由 HIS 系统传输至医保业务组件系统中，进行费用采集。

---

## 接口说明

| 规则       | 说明                                                       |
| ---------- | ---------------------------------------------------------- |
| N 类型字段 | 没有数据时传 `0`                                         |
| 批量       | **只支持单笔**，不支持批量上传                       |
| 幂等       | **支持幂等**                                         |
| 影响范围   | 仅为数据采集接口，**不影响病人在医院的正常结算业务** |

## 调用流程

```
HIS 住院结算（自费/未走医保）
    │
    └─→ 调用 0103（未医保结算住院交易上传）
            │
            ├─ UP_STATUS=0 ─→ 成功
            ├─ UP_STATUS=1 ─→ 数据保存失败（检查 ERR_REASON）
            └─ UP_STATUS=2 ─→ 上传国家平台失败（检查 ERR_REASON）
```
