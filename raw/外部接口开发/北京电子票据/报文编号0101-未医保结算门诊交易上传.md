# 未医保结算门诊交易上传（报文编号 0101）

## 功能描述

在门诊病人 HIS 结算后，将病人费用由 HIS 系统传输至医保业务组件系统中，进行费用采集。

> **注意**：本接口适用于**未走医保结算**的门诊交易（自费病人）。已走医保结算的门诊交易请使用报文编号 **0101（医保结算）** 或 **0303（全自费电子票据信息上传）**。

---

## 接口说明

| 规则       | 说明                                                       |
| ---------- | ---------------------------------------------------------- |
| N 类型字段 | 没有数据时传 `0`                                         |
| 批量       | **只支持单笔**，不支持批量上传                       |
| 幂等       | **支持幂等**                                         |
| 影响范围   | 仅为数据采集接口，**不影响病人在医院的正常结算业务** |

## 调用流程

```
HIS 门诊结算（自费/未走医保）
    │
    └─→ 调用 0101（未医保结算门诊交易上传）
            │
            ├─ STATUS=0 ─→ 成功
            ├─ STATUS=1 ─→ 数据保存失败（检查 ERR_MSG）
            └─ STATUS=2 ─→ 上传国家平台失败（检查 ERR_MSG）
```
